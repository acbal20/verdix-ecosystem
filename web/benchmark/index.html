    🔬 Metodología y honestidad

    • Ejecución real de procesos en este equipo vía /usr/bin/time -v; no hay números estimados.
    • Entrada reproducible: arrays generados con semilla 42 (random.bin / sorted.bin); mismo SHA-256 para todos los lenguajes en cada benchmark.
    • N ejecuciones por medición; se publica mediana, media, σ, p95 y RSS. σ alto = medición poco fiable, mirarla con lupa.
    • Comparables: misma tarea, mismo tamaño, mismo algoritmo. Quicksort propio ≠ Array.sort() de Node.
    • Rust y Go no están instalados en este equipo: no aparecen. Nada se simula.
    • Rust y Go aparecerán cuando se instalen con autorización; el motor ya los detecta vía bench.py list.
    • Los benchmarks dependen del hardware/OS. No mezclar hardware distinto en el mismo gráfico sin advertirlo — latest.json guarda CPU/RAM/kernel en cada corrida.

cd verdix-benchmark
